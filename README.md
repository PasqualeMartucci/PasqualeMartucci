## Featured

### [signal-ui-kit](https://github.com/PasqualeMartucci/signal-ui-kit) · [live demo](https://pasqualemartucci.github.io/signal-ui-kit/)

Reusable Angular 22 components built on signals: a tri-state filter chip that plugs into reactive
forms through `ControlValueAccessor`, and a generic data table where filtering, sorting and
pagination are a chain of `computed()` signals. Zoneless, standalone, tested with Vitest, with CI
and demo deployed by GitHub Actions.
